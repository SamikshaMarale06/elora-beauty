# ÉLORA BEAUTY 🌸

A minimalist skincare e-commerce website built using **React, Tailwind CSS, and JavaScript**.

### Features
- Responsive design
- Product search
- Product categories
- Add to Cart
- Quantity management
- Clean and modern UI

### Run Locally
```bash
npm install
npm run dev
```

### Tech Stack
React • Tailwind CSS • Vite • JavaScript
